# Матрица приёмки

Основание — «Серверная разработка на Python + Flask + MySQL», часть I, с. 6–20. «Проверено» означает, что для указанного критерия есть результат проверки кода или исполнения. «Реализовано» означает, что аудитор нашёл реализацию, а полная проверка ещё требуется. «Не проверено» означает отсутствие подтверждения в целевой среде.
