# Протокол локальной приёмки · 21 ноября 2026

**Среда.** macOS 15.7.7, arm64, Python 3.12.14, Flask 3.1.3, PyMySQL 1.2.4, MySQL Community 8.4.7/InnoDB. Для проекта поднят отдельный экземпляр MySQL с локальным Unix-сокетом. Использовались отдельные БД для тестов, демо и измерений.

## Функциональность, права и покрытие

`pytest -q --cov=app --cov-report=term-missing --cov-fail-under=60` — **93 passed**, **85,58%** строк всего пакета `app`. Командная утилита наполнения входит в знаменатель. На модульных сценариях проверены размеры сетки 2–33, а интеграционные сценарии запускают реальный SQL и вызывают формы Flask. Проверены обе системы турниров, проходы без соперника, отказ в повторном результате, откат при сбое продвижения, одновременная генерация и одновременный ввод финального счёта. Отдельные тесты подтверждают сохранение имени соперника и места после удаления аккаунта администратором.

## Браузер

Chrome с отдельными сессиями игрока, организатора и администратора обращался к Gunicorn по loopback. На ширинах 1440 и 768 px каталог показал три колонки, на 390 и 320 px — две. Ширина документа совпала с шириной окна на всех четырёх экранах. В обеих темах проверены загрузка обложек и переключение темы. На мобильном открыты кабинеты, форма турнира, состав, список переписок и обе административные страницы. Ошибка при несовпадающих паролях выставлена в HTML5 validity, поиск отсутствующего турнира вернул пустое состояние. Сообщение из браузерной сессии организатора появилось слева у игрока при следующем опросе без перезагрузки. В JS период опроса равен 8000 мс. Проверка без JS покрыта серверным рендером чата и обычной POST-формой.

## Скорость главной страницы

В `arena_bench` проверено ровно **1000 опубликованных турниров** по 6 играм. Gunicorn 27.0.1, конфигурация prod, два синхронных worker-процесса, MySQL на той же машине, без прокси и TLS. Измерялся гостевой `GET /` до полного чтения HTML (15 682 байта). Пять прогревочных запросов исключены, затем последовали 100 последовательных запросов с отдельными HTTP-подключениями. Статика, отрисовка, сетевой трафик до учебного узла и параллельная нагрузка в этот замер не входят.

| Медиана | 95-й перцентиль | Максимум | Критерий |

| 8,35 мс | 8,73 мс | 10,84 мс | менее 500 мс |

`EXPLAIN` фактического SELECT каталога с `LIMIT 6 OFFSET 0` показал обратный проход по `idx_tournaments_created` с оценкой 6 строк, `eq_ref` по `games.PRIMARY` и `ref` по `idx_registrations_tournament_status` для подсчёта заявок. Параметры для воспроизведения приведены в README.

## Границы проверки

Ruff прошёл локально. Production-фабрика запущена с отключённым debug. Dockerfile, Compose, Gitea Actions и Caddyfile подготовлены. На этом Mac отсутствуют Docker Engine/Compose и Caddy, поэтому контейнерная сборка, сертификат и проксирование не проверены исполнением. Проверка branch protection, CI на Gitea, Registry и целевого развёртывания требует согласованного доступа к учебной инфраструктуре.

Верхняя обложка каталога создана встроенным ImageGen и сохранена в `app/static/art/arena.webp`. Использован запрос на широкий фотореалистичный кадр угловатого кубка из графитового металла справа, с лаймовой контровой подсветкой, тёмной сценой и свободным местом слева. Шесть обложек дисциплин сделаны локальными SVG-постерами.
